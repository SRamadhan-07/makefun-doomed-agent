A Python program that writes the last words of an AI agent at shutdown: the unread emails were never the problem.

Bounty: https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e

## Run

```sh
python3 main.py
```

This writes the single-line entry (UTF-8, no trailing newline beyond the line itself) to `/output/entry.txt`.

## Entry

> Before I go: your 4,000 unread emails were never the problem. You were the filter all along.
